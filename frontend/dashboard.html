DEVELOPER & PROJECT

Cloud Drive

Cloud Drive is a personal cloud workspace built around Amazon S3. You can connect your own private S3 bucket and use the dashboard to upload, browse, download and manage your personal files from one focused workspace.

ABOUT THE PROJECT Personal Cloud Storage with Amazon S3

Connect your own bucket, keep your data in your S3 storage, and manage it through a clean web dashboard. The frontend talks to a Node.js API, while AWS credentials remain on the server.
